Boilerplate
UTG – Up To Game Pro is an iOS 18+ game companion. Players discover games via IGDB, follow release dates, track prices, keep collections in iCloud, and use optional AI recommendations, chat, and Buy/Wait verdicts. The app also surfaces Epic / Game Pass / giveaway catalogs and, with permission, weather and a map for local play. It supports widgets, Live Activities, and Apple Watch. Sign-in with Apple, Google, or Firebase is optional. UTG Pro+ is an Apple In-App Purchase.
